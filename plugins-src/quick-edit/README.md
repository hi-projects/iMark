# 快速编辑（Quick Edit）

在光标所在行左侧的「+」菜单里插入一张 Markdown 表格。

按钮、菜单与对话框由**宿主**绘制；扩展只负责把对话框里的行数/列数变成一段 Markdown
文本。表格插入后的单元格输入、增删行列与整表操作都是编辑器内建能力，与这个扩展无关。

## 怎么用

1. 把光标放到想插入表格的那一行（行首、行中、行尾都一样）；
2. 点该行左侧的「+」；
3. 菜单里选「表格」；
4. 填行数与列数，确定 —— 表格插入在光标行的**下一行**，并直接停在渲染态。

不想插入就按 Esc，或点菜单外的空白处：文档一个字符都不会动。

## 插在哪一行

**紧贴光标行的下一行**（第 n 行点的「+」，内容就落在第 n+1 行），中间不加空行。

唯一的例外是光标停在已有表格里：插入点会落到**整张表的下方**。Markdown 表格不能在
中间断开，从中间插进去会把原表拆散；落到表下面，新内容是一张独立的表。

## 行数怎么算

**行数含表头。** 填 3 行 3 列得到的是：

```markdown
|       |       |       |
| :---: | :---: | :---: |
|       |       |       |
```

第一行是表头，第二行是 Markdown 表格必需的分隔行，往下才是内容行。所以「3 行」
= 1 行表头 + 2 行内容，填 1 行就只有表头。分隔行写 `:---:`，表头与正文默认居中；
插入后可以用表格右上角的「≡」整表调整对齐。

## 权限与实现

这个扩展遵循 VS Code 的扩展信任模型：**扩展代码以当前用户权限运行，没有权限沙箱**。
它本身不访问网络、不读写文件、不碰密钥；启用前仍应确认扩展来自可信来源。

实现上只做两件事：在 `package.json` 里声明命令 `imark.quick-edit.insertTable` 与一条
`imark.lineMenu` 贡献；被调用时把行数/列数变成 Markdown 文本，通过
`window.activeTextEditor.edit()` 交给 iMark 插入。按钮、菜单、对话框和插入位置全部由
iMark 渲染。

它随应用预置、默认启用（可在「设置 → 扩展」里停用）。停用后「+」菜单里的「表格」
立即消失。
