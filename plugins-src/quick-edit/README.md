# 高级表格（Advanced Table）

在光标所在行的最左侧放一个「+」按钮，点开就能插入表格。

按钮、菜单与对话框由**宿主**绘制，所有声明了 `lineMenu` 的插件会合进同一个「+」菜单；
插件只负责把对话框里的数字变成一段 Markdown 文本。表格插入后的编辑由宿主实现：
**停留在渲染出来的表格里直接输入，不会被翻回 Markdown 源码**。

## 怎么用

1. 把光标放到想插入表格的那一行（放在行首、行中、行尾都一样）；
2. 点该行左边的「+」（按钮跟着光标走，不跟着鼠标走）；
3. 菜单里选「表格」；
4. 填行数与列数，确定 —— 表格插入在这一行的**下方**，并直接停在渲染出的表格里。

## 在表格里编辑

- **点击任意单元格**就地输入。该格会显示这一格的 Markdown 源码（比如 `**加粗**`），
  提交后重新渲染成最终样式；
- **回车**：提交当前格并移到下一行同一列（已经在最后一行时自动加一行）；
- **Tab / Shift+Tab**：提交并移到右 / 左一格；在最后一格按 Tab 会**自动加一行**；
- **Esc**：放弃这一格本次输入，恢复成修改前的样子；
- **点到别处 / 切换文件 / 保存**：当前格的内容自动提交；表格外的正文照常编辑。

单元格里的 `|` 会自动转义成 `\|`，不会被当成列分隔符；换行会被折成空格
（Markdown 表格无法表示单元格内的换行）。

## 增删行列与整张表

表格四周有一圈小控件，**只在能用得上的范围里出现**，平时完全隐藏。
它们浮在表格周围，不占版式空间；表格顶边直接贴住上一行、没有多余的空行，
表格本身仍与正文左对齐。

表格的隐藏源码行（表头行、末尾行）不会成为可输入的行：光标一旦落进去会被自动
挪到表格外的真实正文行；即使输入法组合进行中，文字也不会被写进隐藏源码。
表格上下紧邻的空行只是 Markdown 的分隔，编辑器会把它们折成零高度：视觉间距改由
`--md-table-gap`（或分别用 `--md-table-gap-top` / `--md-table-gap-bottom`）控制。
这两处点不进去，也不会出现「+」；表格下方紧接着的正文行仍然是普通段落
（Markdown 需要的空行分隔仍保留在源码里）。

- 鼠标放在某一格上时，只出现这一行左侧的 `×` 和这一列上方的 `×`；
- 鼠标靠近某条行 / 列边界线（约 10px 内）时，才出现这条线对应的插入 `+`；
- 鼠标在表格上方的留白里时，出现左上角 `▦`（选中整表）和右上角外侧的垃圾桶（删除整表）；
- **按住左键上下拖动**选中连续行，**左右拖动**选中连续列，整行 / 整列高亮后
  按 **Backspace / Delete** 删除；
- 选中整张表后按这两个键也会删表。

## 表格边上的删除键

光标停在表格**上一行行尾**按 Delete，或**下一行行首**按 Backspace 时：

1. **第一次**按键不会改文档，而是把整张表选中（整表高亮）；
2. **再按一次**才删除整张表。

这样不会误删表格与正文之间的换行 —— 那个换行一没，Markdown 表格就会当场散架。

光标停在表格上一行行尾按回车时，只会在上方插入一个空行，光标留在新行上，
不会跳进表格的单元格。

删除表头行时，下一条数据行会接替成为新的表头（Markdown 表格必须有表头）；
只剩一列时删除该列等于删除整张表。列的对齐方式会跟着列一起保留。

表头滚出视口时，整张表会临时退回等宽源码显示 —— 这是渲染方式的限制
（表格整体挂在表头那一行上），把表头滚回来就会恢复成表格。

不想插入就按 Esc，或者点菜单外的空白处：什么都不会发生，文档一个字符都不会动。

## 插在哪一行

**紧贴光标行的下一行**（第 n 行点的「+」，内容就落在第 n+1 行），中间不加空行。
只有两种情况会自己补一个空行，因为不补就会把文档写坏：

- **光标停在已有的表格里**：插入点会落到**整张表**的下方。Markdown 的表格没法在中间断开，
  从中间插进去只会把原来那张表拆散；落到表下面，新内容是一张独立的表，老表一个字符都不少。
- **插入的内容整行是 `-` 或 `=`**：这类「横线」会被 Markdown 读成上一行的标题下划线
  （`正文` 后面跟一行 `---`，得到的是二级标题「正文」而不是分割线），所以上面必须空一行。

## 行数怎么算

**行数含表头。** 填 3 行 3 列得到的是：

```markdown
|     |     |     |
| --- | --- | --- |
|     |     |     |
```

第一行是表头，第二行是 Markdown 表格必需的分隔行，往下才是内容行。所以
「3 行」= 1 行表头 + 2 行内容，填 1 行就只有表头。

分隔行写的是 `---`（不带冒号），也就是 Markdown 的默认对齐：左对齐。

## 关于权限

这个插件的 main 层是 **restricted**（隐藏沙箱页，没有 Node、没有文件系统），**不申请任何权限**（`permissions: []`）。它拿不到你的仓库、文件和密钥，也读不到文档内容 ——
它只做一件事：把你填的两个数字变成一段 Markdown 文本交回给 iMark，由 iMark 自己插入文档。
按钮、菜单、对话框和插入位置也全部由 iMark 渲染，插件代码不参与。

换句话说，即使这个插件写得再糟，它顶多插入一段难看的文本。

它随应用预装、默认启用（可在「设置 → 插件」里关掉）。关掉后「+」按钮就会消失。
