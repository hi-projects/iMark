# AI for Edit

用你自己配置的 AI 服务，整理当前文档的 Markdown 排版，或者在空文档里按一句话生成内容。

插件只负责「把文档发给 AI、把结果放进预览」；**点确认之前不会改文档**。不内置任何
AI 账号，也不经过 iMark 的服务器。

## 配置

在「设置 → 插件 → AI for Edit」里填写：

| 字段 | 说明 |
| --- | --- |
| 服务地址 | 默认 `https://api.deepseek.com/chat/completions`。也可填任意 OpenAI 兼容的 `chat/completions` 完整地址，或 Anthropic 的 `/v1/messages`；只填域名或 `/v1` 时会自动补全。 |
| 模型 | 默认 `deepseek-flash`。换其它服务时填该服务支持的模型名，例如 `gpt-4o-mini`、`moonshot-v1-8k`、`qwen2.5:7b`。 |
| API 密钥 | 加密保存在本机，只会随请求发送到你填写的服务地址。本地服务不需要密钥时可留空。 |
| 请求超时 | 默认 60 秒，范围 5–90 秒。慢模型可以调大。 |
| 显示浮动小人 | 在编辑器里显示一个会动的小人，点它打开对话，按住可以拖到任意位置。默认开启。 |
| 小人形象 | 猫咪 🐱 / 企鹅（动画）🐧 / 机器人 🤖 / 幽灵 👻 / 星星 ✨。企鹅是内置的矢量动画形象。 |

默认配置就是 DeepSeek（`deepseek-flash`）。常见服务地址：

- DeepSeek（OpenAI 兼容）：`https://api.deepseek.com/chat/completions`（默认）
- DeepSeek（Anthropic 兼容）：`https://api.deepseek.com/anthropic/v1/messages`
- OpenAI：`https://api.openai.com/v1/chat/completions`
- Moonshot：`https://api.moonshot.cn/v1/chat/completions`
- 智谱：`https://open.bigmodel.cn/api/paas/v4/chat/completions`
- Anthropic：`https://api.anthropic.com/v1/messages`
- Ollama：`http://127.0.0.1:11434/v1/chat/completions`（模型填 `qwen2.5:7b` 之类）
- Azure OpenAI：`https://<资源名>.openai.azure.com/openai/deployments/<部署名>/chat/completions?api-version=2024-06-01`

配置完成后可以点「测试连接」确认地址、密钥与模型是否可用。

## 使用

### 打开对话

两种方式，打开的是同一个对话窗口：

- 状态栏大纲按钮旁边的 **AI 按钮**；
- 编辑器右下角的**浮动小人**（可在设置里关掉或换形象）。

窗口里可以像网页版对话助手一样提问，例如「这份文档主要在讲什么？」「把这个结论
改得更简洁」。回答会结合当前打开的文档内容。

### 对话

- 在底部输入框提问，Enter 发送，Shift+Enter 换行。
- 每次提问都会把当前文档作为上下文一起发给模型；空文档也会说明「当前文档为空」。
- 对话只回答问题，不会修改文档。
- 「新对话」清空当前聊天记录。

### 快捷按钮：生成 / 美化

窗口顶部有两个按钮：

**生成**（只用于空文档）

1. 在输入框里写想生成的内容，例如「一份产品周报大纲」；
2. 点「生成」，对话里会出现一条「帮我生成：…」的展示消息和生成结果；
3. 结果消息有「预览 / 源码」两个页签：预览是渲染后的 Markdown，源码是原始文本；
4. 检查后点「写入文档」，或点「重新生成」。

**美化**（用于已有内容的文档）

1. 可选：在输入框里写下这次的美化要求，例如「更正式」「精简一点」「按小节分点」；
   不写就交给 AI 自行整理；
2. 点「美化」，对话里会出现「帮我美化一下这份文档」或「帮我美化一下这份文档：…」；
3. 结果消息的**预览本身就是差异视图**：未变化内容正常渲染，新增/修改的内容绿底，
   删除的内容红底并划掉；不再单独放一块逐行差异；
4. 「源码」页签保留最终的 Markdown；点「确认替换」写回，或点「重新生成」。

生成/美化结果在确认前都不会改文档；如果确认时文档已经在期间被修改，会拒绝写入并
提示重新生成。文档开头的 YAML front matter 会被**原样保留**，不会发给模型。

行首「+」→「AI 生成内容」在空文档里会打开对话并直接触发生成；**非空文档**用「+」
生成时仍保持原来的行为：内容直接插入到「+」所在行的下方。

### 浮动小人

- 设置里可以关掉浮动小人，或从猫咪 / 企鹅（动画）/ 机器人 / 幽灵 / 星星中切换形象。
- 企鹅是独立的透明背景动画角色，不套圆形气泡；其它 emoji 形象保留小圆钮外观。
- **按住小人可以拖到编辑器里的任意位置**，位置会在下次打开应用时保留。
- 小人只是另一个打开对话的入口；关掉后状态栏按钮仍然可用。

## 安全与边界

- **文档内容会发送到你配置的服务地址**。不要在不信任的服务上处理敏感文档。
- 密钥由宿主加密保存；插件的日志不会记录密钥，也不会记录文档正文。
- 对话提问会把当前文档作为上下文发送给配置的服务；美化/生成也一样。不要在不信任
  的服务上处理敏感文档。
- AI 结果只进入对话消息；**点确认之前不会修改文档**。关闭窗口或请求失败都不会留下
  半个结果。
- 美化时如果 AI 输出被截断（达到模型输出上限）、明显短于原文，或内容为空，
  插件会拒绝这次结果，文档一个字符都不会变。
- 整篇美化/生成的正文上限约 12 万字符；AI 返回内容上限约 18 万字符。
- 不支持流式输出；预览期间文档如果被修改，确认时会拒绝写回并提示重新生成。
- 主进程使用的是 Node 的 `fetch`，**不读取系统代理**。需要代理时，请让服务地址
  可以直连，或在本机起一个反向代理。

## 常见错误

| 提示 | 通常原因 |
| --- | --- |
| 认证失败（401/403） | 密钥错误、过期，或该服务要求 `Bearer` 之外的认证头。 |
| 接口地址不对（404） | 地址少了 `/v1/chat/completions`，或模型名不被该服务支持。 |
| 请求过于频繁或额度不足（429） | 触发了限流，或账户余额不足。 |
| 连接被拒绝 / 域名解析失败 | 本地服务没有启动、端口不对，或网络不可达。 |
| 文档在 AI 处理期间被修改 | 请求期间你编辑了文档；重新执行一次即可。 |
